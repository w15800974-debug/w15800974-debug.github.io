# وب‌سایت و پورتفولیوی تعاملی دوزبانه (فارسی / انگلیسی) — علی حاجیان

وب‌سایت رسمی و پورتفولیوی تعاملی **علی حاجیان** (توسعه‌دهنده هوش مصنوعی، تکنولوژیست خلاق و کارآفرین دیجیتال) با پشتیبانی کامل از دو زبان **فارسی (زبان پیش‌فرض - راست‌چین با فونت وزیرمتن)** و **انگلیسی (چپ‌چین)**.

## 🌐 لینک مشاهده مستقیم وب‌سایت (زنده و آنلاین)

* **آدرس اصلی GitHub Pages:** [https://w15800974-debug.github.io/](https://w15800974-debug.github.io/)

## ✨ امکانات و بخش‌های وب‌سایت

* **سوییچر آنی زبان (FA / EN):** تغییر در لحظه بین زبان فارسی (`RTL` با تایپوگرافی استاندارد فارسی `Vazirmatn` و ارقام فارسی) و انگلیسی (`LTR`) از نوار ابزار بالا یا پالت فرمان (`⌘K` / `Ctrl+K`).
* **گوی عصبی سه‌بعدی (Neural Orb):** شبیه‌سازی زنده شبکه عصبی با قابلیت تغییر هندسه (کره، چنبره، مارپیچ، مکعب، موج) و انتشار سیگنال با کلیک.
* **نقشه عصبی مهارت‌ها (Neural Map):** گراف فیزیکی تعاملی با قابلیت کشیدن گره‌ها (Drag) و فیلتر بر اساس حوزه تخصصی.
* **آزمایشگاه زنده (The Lab):**
  * **زمین بازی شبکه عصبی:** آموزش زنده یک شبکه عصبی چندلایه (`7→10→8→1`) با الگوریتم انتشار برگشتی (Backpropagation) و بهینه‌ساز Adam در مرورگر.
  * **کارگاه نشان مولد (Sigil Forge):** تبدیل متن فارسی یا انگلیسی به نماد هندسی متقارن یکتا با قابلیت دانلود تصویر PNG.
* **گفتگو با همزاد هوشمند (ALI·TWIN):** چت‌بات تعاملی دوزبانه که به پرسش‌های فارسی و انگلیسی درباره مهارت‌ها، پروژه‌ها و نحوه همکاری پاسخ می‌دهد.
